# 🎮 GameVault - Local Game Library & Launcher (สไตล์ Steam)

โปรแกรมจัดการคลังเกมและเปิดเกมในเครื่องอัตโนมัติ สไตล์ Steam Library สำหรับ Windows

---

## ✨ ฟีเจอร์ใหม่ที่อัปเกรดล่าสุด (New Updates)

1. **สไลเดอร์ปรับขนาด Thumbnail การ์ดเกม (Card Size Zoom Slider)**
   - มีแถบเลื่อน **Size: [—o—]** ที่แถบเมนูด้านบน เลื่อนปรับขนาดการ์ดเกมได้อย่างอิสระ (120px - 260px)
   - โปรแกรมจะจำค่าขนาดที่คุณชอบไว้ให้อัตโนมัติ

2. **แก้ปัญหาตรวจจับชื่อเกมติด Engine (เช่น Unity / Unreal)**
   - เพิ่มระบบกรองชื่อเอนจิ้น (`Unity`, `Unity Player`, `Unreal Engine`, `Godot`, ฯลฯ) ไม่ให้กลายมาเป็นชื่อเกม
   - ทำให้เกมที่พัฒนาด้วย Unity อย่างเช่น **Rune Factory 3 Special** ไม่ถูก detect เป็น "Unity" หรือดึงปก "Assassin's Creed Unity" อีกต่อไป

3. **ระบบเปลี่ยนไฟล์ .exe ของเกมได้ง่ายและแม่นยำ (Change Executable)**
   - หากตัวเกม detect ไฟล์ `.exe` ผิดตัว (เช่น ไปชี้ที่ crash handler หรือ launcher) คุณสามารถเปลี่ยนได้ทันที 2 ช่องทาง:
     - **ในหน้ารายละเอียดเกม:** มีปุ่ม **"🎯 Change .exe"** อยู่ข้างๆ ชื่อไฟล์ Executable
     - **คลิกขวาที่การ์ดเกม:** เลือก **"🎯 Change Executable (.exe)"**
   - **ระบบค้นหาไฟล์ .exe อัตโนมัติในโฟลเดอร์:** เมื่อกดเปลี่ยน โปรแกรมจะสแกนโฟลเดอร์เกมนั้นเพื่อลิสต์ไฟล์ `.exe` ทั้งหมดที่มี (พร้อมแสดงขนาดไฟล์ เช่น 65 MB) ให้คุณคลิกเลือกได้ในคลิกเดียว โดยไม่ต้องเสียเวลาค้นหาเองในโฟลเดอร์ลึกๆ เช่น `bin/x64/`
   - มีปุ่ม **"📂 Browse .exe Manually (ค้นหาไฟล์เอง)"** สำหรับเลือกไฟล์จากหน้าต่าง Windows Explorer ได้อย่างอิสระ

4. **Rename แล้วดึงปกและข้อมูลใหม่ให้อัตโนมัติ (Auto Re-fetch on Rename)**
   - เมื่อกด **Rename** เปลี่ยนชื่อเกม โปรแกรมจะขึ้นถามทันทีว่า *ต้องการค้นหาปกและข้อมูลเกมใหม่จาก Steam ด้วยชื่อใหม่หรือไม่?* 
   - หากกดยืนยัน โปรแกรมจะค้นหาและเปลี่ยนปกพร้อมอัปเดตข้อมูลให้อัตโนมัติทันที

5. **ค้นหาปกพร้อมแสดงรูปภาพตัวอย่างจริงให้เลือกทันที (Visual Online Cover Search)**
   - เมื่อกดค้นหาปกออนไลน์ หรือเปิดหน้าต่าง Search Cover Online:
     - โปรแกรมจะแสดงภาพปกแนวตั้ง (Portrait Cover Art 600x900) ของแต่ละผลการค้นหาให้เห็นจริงบนหน้าจอ
     - ไม่ต้องลุ้นหรือเดาชื่ออีกต่อไป เห็นรูปปกจริงก่อนเลือก พร้อมชื่อเกมและ Steam AppID
     - สามารถคลิกที่รูปการ์ด หรือปุ่ม **"✔ Use This Cover"** เพื่อเลือกใช้รูปนั้นได้ทันที 
     - **รองรับวางลิงก์รูปภาพจากเว็บอื่น (Direct Image URL):** ในช่อง Method 2 สามารถวางลิงก์รูปภาพจากเว็บใดก็ได้ (เช่น SteamGridDB, IGDB, Google Images, Imgur ฯลฯ) โปรแกรมจะดาวน์โหลดและ **Auto-Resize / Center-crop เป็น 600x900 สัดส่วนปกแนวตั้ง Steam พอดีเป๊ะ** โดยไม่บิดเบี้ยวให้อัตโนมัติทันที
      - รองรับทั้งการพิมพ์ชื่อค้นหา และการวางลิงก์หน้าร้านค้า Steam / AppID เพื่อดึงข้อมูลตรงเป๊ะ 100%
      - **ดึงปกพร้อมกันทั้ง Steam Store และ SteamGridDB ใน Method 1:** ไม่ต้องสลับ dropdown ดึงปกทางการและปก Custom Fan-art มาแสดงเทียบกันให้เลือกได้ในคลิกเดียว พร้อมปุ่ม `⚙ Settings` สำหรับตั้งค่า SteamGridDB API Key

6. **ระบบเปลี่ยนสีกรอบการ์ดเกม (Card Border Color Highlight)**
   - สามารถเปลี่ยนสีกรอบของการ์ดเกมแต่ละใบ เพื่อไฮไลท์และแยกหมวดหมู่เกมได้อย่างชัดเจน:
     - 🔴 **แดง:** เหมาะสำหรับเกม 18+ / Mature
     - 🔵 **ฟ้า:** เกมออนไลน์ / Multiplayer / Co-op
     - 🟣 **ม่วง:** อนิเมะ / RPG / เกมพิเศษ
     - 🟢 **เขียว:** เล่นจบแล้ว / Cozy games
     - 🟡 **เหลืองทอง:** เกมโปรด / Favorite ⭐
     - 🟠 **ส้ม:** เกมแอ็กชัน / กำลังเล่น
     - 🌸 **ชมพู:** Visual Novel / Indie
     - 🌈 **Custom Color:** ใช้ Color Picker เลือกสีใดก็ได้ตามใจชอบ
   - **เปลี่ยนได้ 2 ช่องทางสะดวกสุดๆ:**
     - **คลิกขวาที่การ์ดเกม:** เมนู `🎨 Border Color (สีกรอบ)` -> คลิกเลือกสีที่ต้องการได้ทันทีใน 1 วินาที!
     - **ในหน้ารายละเอียดเกม:** กดปุ่ม `🎨 Set Border Color (สีกรอบ)`

7. **หน้ารายละเอียดเกม พร้อมคำอธิบายย่อ และ Screenshots 3-4 ภาพ (Steam Store View)**
   - เมื่อคลิกที่การ์ดเกม จะเปิดหน้าต่างพรีวิวที่มี:
     - ปกเกมขนาดใหญ่ (พร้อมกรอบสีที่ตรงกับที่เราตั้งไว้)
     - **About The Game:** คำอธิบายรายละเอียดของเกม (ดึงจาก Steam)
     - **Screenshots:** ภาพตัวอย่างเกม 3-4 รูป สามารถคลิกที่ภาพเพื่อเปิดดูภาพขนาดเต็ม (Full-screen preview) ได้
     - แท็กหมวดหมู่ (Genres), วันวางจำหน่าย (Release Date), ผู้พัฒนา (Developer)
     - ปุ่ม **View on Steam** สำหรับเปิดหน้า Steam ในเว็บเบราว์เซอร์
     - ปุ่ม **Attach Steam Store Link** สำหรับผูกลิงก์หน้าร้านค้า Steam
     - ปุ่ม **Refresh Info from Steam** สำหรับดึงข้อมูลล่าสุด
